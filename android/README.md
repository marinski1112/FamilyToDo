# FamilyToDo Android ネイティブ化（開発途中）

Android Studioで `android/` を開き、Gradle Sync後にデバッグAPKを端末へインストールします。ストア登録は不要です。身内へ配るAPKは自分たちで保持する署名鍵を使ってください。署名鍵・端末Secretはリポジトリに追加しません。内部配布用の署名と上書き更新の準備は [INTERNAL_RELEASE.md](INTERNAL_RELEASE.md) に記載しています。

通常のアプリアイコンにはWebアプリ標準の `public/assets/pwa-512.png` を組み込んでいます。家族ごとにWebの「ホーム画面」で設定した画像と表示名を使う場合は、ログイン後の「ホーム画面アイコン」からAndroidのショートカット追加画面を開いてください。既存のランチャーアイコン自体はインストール後に任意の家族画像へ変更できないため、家族アイコンのショートカットをホーム画面に追加します。Web側で画像を変えた後はショートカットを作り直してください。

## デバッグAPKの接続先

通常のデバッグビルドは本番URLに接続します。Android用APIをプレビュー環境へデプロイし、専用の認証設定・D1・位置情報送信先を確認した場合だけ、次の形式で接続先を指定できます。

```sh
gradle -p android :app:assembleDebug -PfamilytodoDebugOrigin=https://YOUR-WORKER.marinski1112.workers.dev
```

指定できるのは `marinski1112.workers.dev` 内のHTTPSオリジンだけです（パス・末尾のスラッシュ不可）。このビルドは `jp.marinski.familytodo.preview` として別アプリになり、表示名は「FamilyToDo Preview」です。APIとログインWebViewは指定した同一オリジンへ向かいます。**プレビューAPKは書き込み禁止**で、位置情報送信も開始しません。LINEログインのコールバックとLIFF許可ドメイン、D1や位置情報の保存先がそのプレビューに対応していなければログイン・共有は動きません。接続先の指定だけで実機テスト可能とは判断しないでください。通常のCI artifactは従来どおり本番URL向けです。

端末のライト／ダーク設定に応じてネイティブ画面のテーマを切り替えます。実機で文字と入力欄のコントラストを確認してください。

## Androidバージョン別の確認

最小SDKは26（Android 8）、現行のtarget/compile SDKは35です。手元のGalaxy A21（Android 11）を最初の実機確認に使い、その後のOSでも互換性を継続して確認します。新しいOSでの動作をCIのAPK生成だけから保証しません。

| OS | 位置共有と権限の確認点 |
| --- | --- |
| Android 11 | 位置情報の「常に許可」を設定画面から付与し、共有ON・OFFと再起動後の扱いを確認 |
| Android 12以降 | 「おおよその位置」だけを許可した場合も共有を開始し、位置の精度表示と停止を確認 |
| Android 13以降 | 位置共有の開始時に通知の許可を求める。拒否しても共有は開始できるが、通知欄には共有中の通知が表示されないため、OSのタスクマネージャーとアプリ内の停止導線を確認 |
| Android 14以降 | foreground serviceの位置情報権限、バックグラウンドからの再開制限と権限取り消し後の動作を実機で確認 |

OS更新時は、画面・ログイン・写真選択・位置共有の開始／停止・再起動後の再開・通知・上書き更新を回帰確認します。未検証の新バージョンは対応を確定した扱いにしません。

## 現在のネイティブ画面

- 月ごとのカレンダー：イベントとタスク、スタンプの印を表示します。選択日の一覧はイベントを先に表示し、イベントを長押しして編集操作を開けます。選択した日のスタンプ画像を読み込み、アニメーションスタンプはタップ後に再生できます（GIF/WebPはAndroid 9以降）。タスクを完了・未完了に切り替えます。既存スタンプを家族公開・自分限定で配置し、タップして自分の配置を好きな表示位置・先頭・末尾や別の日へ移動・削除できます。管理者は端末の画像から静止画スタンプと、2〜48枚のPNGをファイル名順に再生する動くスタンプを登録できます。フレームの縦横サイズを揃え、共有用に合計1MiB以内へ自動縮小します。スタンプ管理のページ送り一覧から有効・無効を切り替えられます。配置者・登録権限はサーバーで判定します。
- 買い物・持ち物：種類別のカテゴリ順に一覧表示し、完了切り替え、カテゴリ・数量（買い物）・メモ・URL・期限日付きの新規追加ができます。項目を長押しすると詳細・カテゴリの編集、完了履歴の表示、削除ができます。詳細編集・削除は作成者または管理者に限ります。カテゴリ名をタップすると改名・好きな位置への移動・上下移動・削除ができます。カテゴリ名の長押しから別のカテゴリ名へドラッグしても順序を変更できます。カテゴリ削除は管理者のみで、項目は未分類へ移します。種類別のセットは表示中の未完了項目から作成し、日付を選んで呼び出し、権限があれば削除できます。持ち物セットは名前と各項目の追加・編集・削除・順序変更にも対応します。
- カレンダーから終日または同日内の時刻指定タスク・イベントを作成し、説明と場所も入力できます。通常のタスク・イベントを長押しして日時・公開範囲・通知などを編集または削除できます。管理者は「定期タスク」から繰り返し予定を作成・編集（シリーズ全体／指定日以降）・停止・再開・削除でき、除外済みの発生日を復活できます。カレンダー上の繰り返し予定を長押しするとシリーズ編集か、この回だけ通常タスクとして切り出して編集できます。切り出し後に編集画面を閉じても、切り出し自体は取り消されません。伝言タブでは直近の伝言、添付写真とスタンプを読み、家族全員または個別の家族へのテキスト・スタンプ伝言と既存の通知予約を送れます。開いた伝言は既読を同期し、自分の伝言には既読数を表示します。伝言を長押しするとリアクションを付け外し、買い物や終日・日付なしのタスク／イベントに変換できます。送信者または管理者は編集・削除でき、管理者はリアクション候補も編集できます。即時のテキスト・スタンプ伝言は既存の通知APIを呼びます。写真付き伝言は端末の写真選択画面から家族全員へ送信できます。失敗時はアプリを開いている間、同じ写真送信内容を再試行できます。Google Homeでの読み上げ・音楽再生は後続の作業です。
- 育児タブ：日付ごとの記録と対象を表示します。対象の追加・設定編集・非表示、ミルク・おむつ・離乳食の簡易入力、日時・数値・時間・内容を指定する一般入力、記録の長押し編集・削除ができます。家族メンバー連携の対象は非表示にできません。赤ちゃん・子どもの離乳食記録には写真を追加・表示・削除できます。今日のクイック記録とちょこっと家事の実行、睡眠・汎用タイマーの開始と終了、表示日の簡易集計、対象を選べる今日・7日・30日または任意の1〜366日の集計、集計期間末尾30日までのミルク量・睡眠時間・記録件数・おむつ・食事・トイレ・入浴・薬・家事の切替式棒グラフ、管理者の表示設定に対応します。管理者はクイック記録を追加・編集・並べ替え・無効化・再有効化できます。権限のある人はちょこっと家事の項目を追加・編集・並べ替え・非表示・再表示できます。登録・編集・削除は既存の家族ログAPIを使います。
- 画面起動時と月切り替え時に認証済みAPIからデータを読みます。月データとスタンプ配置はKeystore鍵で暗号化し、ログインセッションに結び付けて端末内に最大7日・前後2か月の範囲で保存します。開いた育児記録も最大7日付分を暗号化して保存し、通信できない時は操作・実行中タイマーを隠した読み取り専用画面で表示します。表示月の縮小画像は最大24種類、選択日のPNGアニメーションは最大16フレーム、GIF/WebPは最大2件を先読みします。端末内の画像キャッシュはPNG最大64件・24MiB、GIF/WebP最大4件・20MiBです。同じセッションが残っているオフライン時は読み取り専用で表示し、ログアウト時は削除します。セッションが更新された場合は再取得が必要です。WebViewは既存のログインを行う間だけ表示します。同じ接続先のアプリ画面へログイン後に遷移したらネイティブ画面へ自動で戻ります。戻らない場合は手動の復帰ボタンを使えます。
- アプリ設定：「Google連携の状態」を開くと、Google Calendarの接続・最終送信と本人のGoogle Tasksの状態・最終受信・競合累計を必要時だけ読み取れます。プロフィール名、本人の通知ON/OFF、家族メンバー一覧、管理者のメンバー停止・再開、ちょこっと家事の管理権限付与・解除と招待リンク共有、家族タイムゾーンとホーム画面の表示名をネイティブ画面で変更できます。変更時は既存のWebと同じ設定APIを使います。タイムゾーン変更は過去の記録日時を変換しません。
- 位置設定：アプリ内から自分のAndroid端末を新規登録し、発行されたSecretをKeystoreへ保存してWeb側の共有もONにできます。既存のAndroid端末ID・Secretを手入力する方法も残しています。保存済み端末の共有再開と共有停止はWeb側の状態も同期します。ログアウト時は端末の送信を先に停止し、Web側の共有OFFを試みてからCookieを削除します。同期できなかった場合は表示で知らせます。開始中はforeground serviceの通知を作成します。Android 13以降で通知を拒否した場合、通知欄への表示はOSにより抑止されます。OSが実行中のサービスを再生成した場合は、端末に保存した開始状態を確認して再開します。停止はアプリの位置設定またはWeb側の共有OFF／失効で行えます。再起動後とアプリ更新後は、共有ONかつ保存済みSecretがあり、必要な位置情報権限がある場合だけ再開します。Android 10以降はバックグラウンド位置情報の許可（「常に許可」）が必要です。許可がない場合はアプリを開いて手動で再開してください。

まだ全機能は使えません。繰り返し予定のこの回だけの編集や認証画面を含め、実機E2Eは未検証です。育児記録のWebと同等のすべての詳細グラフ、その他のWeb設定などは未実装です。先読み枠を超えるスタンプ・アニメーションと育児記録・伝言の写真はオンライン時に読み込みます。オフラインの編集キュー・更新競合処理、端末再起動後の自動再開は実機で未検証です。Android画面を本番利用する前に各機能の権限・同期・復旧を確認してください。

端末SecretはAndroid Keystoreで暗号化し、WebViewへ渡しません。サーバーは共有OFF・失効・端末種別を毎回検証し、位置履歴と最新位置の既存D1テーブルを共用します。ネイティブのデータAPIはログイン済み家族の可視範囲で月単位に取得します。
