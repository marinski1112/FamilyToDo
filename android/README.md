# FamilyToDo Android 初版

Android Studioでこの `android/` ディレクトリを開き、Gradle Sync後に個人の端末へデバッグAPKをインストールします。Play Store公開や署名鍵の配布は不要です。配布用APKは自分たちで管理する署名鍵を用意してください。署名鍵や端末のSecretをリポジトリへ追加しないでください。

既存のWeb画面をアプリ内で表示します。ログインはWebの既存認証を利用します。画面上部の「Android位置設定」から、Webの「位置情報・端末連携」で新規発行したAndroid端末IDとSecretを入力し、Web側で位置共有をONにしてから「保存して開始」を押します。端末で位置・通知権限を許可します。位置送信中は通知を表示し、「共有を停止」またはWeb側の共有OFF／失効で停止できます。端末側の停止後に再開する場合は再び設定画面から開始します。

この初版は起動中のforeground serviceでGPSとネットワーク位置を受け取ります。OSや端末の省電力制御で停止する場合があり、自動再開・オフライン送信キューは未実装です。現在のWeb画面を表示するため通信が必要です。スタンプやカレンダーの個人データの事前保存も未実装です。

端末SecretはAndroid Keystoreで暗号化し、WebViewへ渡しません。サーバーは共有OFF・失効・端末種別を毎回検証し、既存の位置履歴と最新位置のD1テーブルを共用します。
