# FamilyToDo Android ネイティブ化（開発途中）

Android Studioで `android/` を開き、Gradle Sync後にデバッグAPKを端末へインストールします。ストア登録は不要です。身内へ配るAPKは自分たちで保持する署名鍵を使ってください。署名鍵・端末Secretはリポジトリに追加しません。

## 現在のネイティブ画面

- 月ごとのカレンダー：イベントとタスクを表示し、タスクを完了・未完了に切り替えます。
- 買い物・持ち物：一覧表示、完了切り替え、名前だけの新規追加ができます。
- カレンダーから終日のタスク・イベントを作成できます。伝言タブでは直近の伝言を読み、家族全員へのテキスト伝言を送れます。
- 画面起動時と月切り替え時に認証済みAPIからデータを読みます。月データはKeystore鍵で暗号化して端末内に最大7日・前後2か月の範囲で保存し、オフライン時は読み取り専用で表示します。ログアウト時は削除します。WebViewは既存のログインを行う間だけ表示します。
- 位置設定：Webの「位置情報・端末連携」で発行したAndroid端末ID・Secretを入力し、Web側で共有ONにして開始します。開始中はforeground通知を表示します。停止はアプリの位置設定またはWeb側の共有OFF／失効で行えます。

まだ全機能は使えません。繰り返し予定の表示や認証画面を含め、CIでAPKビルドは成功していますが実機E2Eは未検証です。スタンプと写真付き伝言の内容表示・送信、伝言の宛先／予約、育児記録、カテゴリ管理、詳細編集、設定などは未実装です。オフラインの編集キュー・更新競合処理、OSによる位置サービス停止後の再開は未実装です。Android画面を本番利用する前に各機能の権限・同期・復旧を確認してください。

端末SecretはAndroid Keystoreで暗号化し、WebViewへ渡しません。サーバーは共有OFF・失効・端末種別を毎回検証し、位置履歴と最新位置の既存D1テーブルを共用します。ネイティブのデータAPIはログイン済み家族の可視範囲で月単位に取得します。
