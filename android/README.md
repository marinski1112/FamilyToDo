# FamilyToDo Android ネイティブ化（開発途中）

Android Studioで `android/` を開き、Gradle Sync後にデバッグAPKを端末へインストールします。ストア登録は不要です。身内へ配るAPKは自分たちで保持する署名鍵を使ってください。署名鍵・端末Secretはリポジトリに追加しません。

## 現在のネイティブ画面

- 月ごとのカレンダー：イベントとタスク、スタンプの印を表示します。選択した日のスタンプ画像を読み込み、アニメーションスタンプはタップ後に再生できます（GIF/WebPはAndroid 9以降）。タスクを完了・未完了に切り替えます。既存スタンプを家族公開・自分限定で配置し、タップして自分の配置を先頭・末尾や別の日へ移動・削除できます。管理者は端末の画像から静止画スタンプを登録できます。配置者・登録権限はサーバーで判定します。
- 買い物・持ち物：種類別のカテゴリ順に一覧表示し、完了切り替え、カテゴリ・数量（買い物）・メモ・URL・期限日付きの新規追加ができます。項目を長押しすると詳細・カテゴリの編集、完了履歴の表示、削除ができます。詳細編集・削除は作成者または管理者に限ります。カテゴリ名をタップすると改名・上下移動・削除ができます。カテゴリ削除は管理者のみで、項目は未分類へ移します。
- カレンダーから終日または同日内の時刻指定タスク・イベントを作成し、説明と場所も入力できます。通常のタスク・イベントを長押しして日時・公開範囲・通知などを編集または削除できます。管理者は「定期タスク」から繰り返し予定を作成・編集（シリーズ全体／指定日以降）・停止・再開・削除でき、除外済みの発生日を復活できます。カレンダー上の繰り返し予定を長押しすると該当ルールを開きます。伝言タブでは直近の伝言と添付写真を読み、家族全員または個別の家族へのテキスト伝言と既存の通知予約を送れます。写真付き伝言は端末の写真選択画面から家族全員へ送信できます。失敗時はアプリを開いている間、同じ送信内容を再試行できます。Google Homeでの読み上げ・音楽再生は後続の作業です。
- 育児タブ：日付ごとの記録と対象を表示します。対象の追加・設定編集・非表示、ミルク・おむつ・離乳食の簡易入力、日時・数値・時間・内容を指定する一般入力、記録の長押し編集・削除ができます。家族メンバー連携の対象は非表示にできません。赤ちゃん・子どもの離乳食記録には写真を追加・表示・削除できます。今日のクイック記録とちょこっと家事の実行、睡眠・汎用タイマーの開始と終了、表示日の簡易集計、対象を選べる今日・7日・30日の集計、管理者の表示設定に対応します。管理者はクイック記録を追加・編集・並べ替え・無効化・再有効化できます。権限のある人はちょこっと家事の項目を追加・編集・並べ替え・非表示・再表示できます。登録・編集・削除は既存の家族ログAPIを使います。
- 画面起動時と月切り替え時に認証済みAPIからデータを読みます。月データとスタンプ配置はKeystore鍵で暗号化し、ログインセッションに結び付けて端末内に最大7日・前後2か月の範囲で保存します。開いた育児記録も最大7日付分を暗号化して保存し、通信できない時は操作・実行中タイマーを隠した読み取り専用画面で表示します。表示月の縮小画像は最大24種類、選択日のPNGアニメーションは最大16フレーム、GIF/WebPは最大2件を先読みします。端末内の画像キャッシュはPNG最大64件・24MiB、GIF/WebP最大4件・20MiBです。同じセッションが残っているオフライン時は読み取り専用で表示し、ログアウト時は削除します。セッションが更新された場合は再取得が必要です。WebViewは既存のログインを行う間だけ表示します。
- 位置設定：Webの「位置情報・端末連携」で発行したAndroid端末ID・Secretを入力し、Web側で共有ONにして開始します。開始中はforeground通知を表示します。OSが実行中のサービスを再生成した場合は、端末に保存した開始状態を確認して再開します。停止はアプリの位置設定またはWeb側の共有OFF／失効で行えます。端末再起動後の自動開始は行いません。

まだ全機能は使えません。繰り返し予定のこの回だけの編集や認証画面を含め、実機E2Eは未検証です。スタンプの任意位置への並べ替え・複数フレーム登録、育児記録のWebと同等の詳細グラフ・自由期間集計、カテゴリのドラッグ操作、その他のWeb設定などは未実装です。先読み枠を超えるスタンプ・アニメーションと育児記録・伝言の写真はオンライン時に読み込みます。オフラインの編集キュー・更新競合処理、端末再起動後の位置共有再開は未実装です。Android画面を本番利用する前に各機能の権限・同期・復旧を確認してください。

端末SecretはAndroid Keystoreで暗号化し、WebViewへ渡しません。サーバーは共有OFF・失効・端末種別を毎回検証し、位置履歴と最新位置の既存D1テーブルを共用します。ネイティブのデータAPIはログイン済み家族の可視範囲で月単位に取得します。
