# FamilyToDo Android ネイティブ化（開発途中）

Android Studioで `android/` を開き、Gradle Sync後にデバッグAPKを端末へインストールします。ストア登録は不要です。身内へ配るAPKは自分たちで保持する署名鍵を使ってください。署名鍵・端末Secretはリポジトリに追加しません。

## 現在のネイティブ画面

- 月ごとのカレンダー：イベントとタスク、スタンプの印を表示します。選択した日のスタンプ画像を読み込み、タスクを完了・未完了に切り替えます。
- 買い物・持ち物：種類別のカテゴリ順に一覧表示し、完了切り替え、カテゴリ・数量（買い物）・メモ・URL・期限日付きの新規追加ができます。項目を長押しするとカテゴリを変更できます。カテゴリ名をタップすると改名・上下移動・削除ができます。削除は管理者のみで、項目は未分類へ移します。
- カレンダーから終日のタスク・イベントを作成できます。伝言タブでは直近の伝言を読み、家族全員または個別の家族へのテキスト伝言と既存の通知予約を送れます。Google Homeでの読み上げ・音楽再生は後続の作業です。
- 画面起動時と月切り替え時に認証済みAPIからデータを読みます。月データはKeystore鍵で暗号化し、ログインセッションに結び付けて端末内に最大7日・前後2か月の範囲で保存します。同じセッションが残っているオフライン時は読み取り専用で表示し、ログアウト時は削除します。セッションが更新された場合は再取得が必要です。WebViewは既存のログインを行う間だけ表示します。
- 位置設定：Webの「位置情報・端末連携」で発行したAndroid端末ID・Secretを入力し、Web側で共有ONにして開始します。開始中はforeground通知を表示します。停止はアプリの位置設定またはWeb側の共有OFF／失効で行えます。

まだ全機能は使えません。繰り返し予定の表示や認証画面を含め、CIでAPKビルドは成功していますが実機E2Eは未検証です。スタンプの配置・編集やアニメーション、写真付き伝言の内容表示・送信、育児記録、カテゴリのドラッグ操作、項目の詳細編集、設定などは未実装です。スタンプ画像はオンライン時に読み込みます。オフラインの編集キュー・更新競合処理、OSによる位置サービス停止後の再開は未実装です。Android画面を本番利用する前に各機能の権限・同期・復旧を確認してください。

端末SecretはAndroid Keystoreで暗号化し、WebViewへ渡しません。サーバーは共有OFF・失効・端末種別を毎回検証し、位置履歴と最新位置の既存D1テーブルを共用します。ネイティブのデータAPIはログイン済み家族の可視範囲で月単位に取得します。
