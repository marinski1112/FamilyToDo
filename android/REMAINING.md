# Android ネイティブ化の残作業

PR #1143 は開発中です。Google Homeの読み上げ・音楽は依頼どおり後回しにします。iPhoneの位置共有は既存の外部アプリを使います。

## 完了済みの範囲

実装済みの操作と端末キャッシュは [README.md](README.md) に記載しています。Webと同じD1を既存API経由で使用します。カレンダー、チェックリスト、伝言、育児記録、スタンプ、Android位置共有の登録・開始・停止をネイティブ画面へ移しました。ログインのみ既存Web画面を使います。家族固有のPWAアイコンはホーム画面ショートカットへ反映できます。

## 今回まとめて追加したUI

ホームの要対応・4件の実数カウンター・昨日の日誌・占い、カレンダー内の重なりスタンプ・背景ステッカー（家族公開／自分だけ）をWebの元ソースに合わせて追加。背景保存の成功・失敗・削除・読み取り専用を隔離fixtureで確認する。途中APKごとのログイン確認は求めず、検証後の版をまとめて配布する。

## 残りの優先順位

1. **APIとAPKの整合**：デバッグAPKはAndroid CIの `familytodo-android-debug` artifactとして7日間保存され、通常ビルドは本番URLに接続する。`familytodoDebugOrigin` を指定すれば別アプリID・書き込み禁止のプレビューAPKをビルドできるが、PR #1143 のAndroid用APIは本番未反映。PRプレビューのwrangler設定は本番と同じD1・R2のIDを参照するため、書き込み実機E2Eへ使用しない。プレビューで先に検証するには、Android用API、LINEログイン・LIFF、専用D1、位置情報送信先を揃えた環境を構築してから専用APKをビルドする。設定だけのプレビューAPKを実機テスト可能と扱わない。
2. **実機確認と配布**：Galaxy A21などの実機でログイン、権限、画面の表示、写真、スタンプ、位置共有、オフラインからの復帰を一通り確認する。内部配布用の署名ワークフローと手順は `INTERNAL_RELEASE.md` に用意済み。鍵を安全に作成・保管してGitHub Secretsへ設定し、同じ鍵のAPKで上書き更新できるか確認する。現時点で署名済みAPKは未作成。CI成功は端末での動作保証ではない。
3. **日常操作の差分**：育児記録のWebと同等の詳細グラフ（期間集計の10項目の棒グラフは実装済み。時間帯・推移などWeb固有の表示は未比較）、残るWeb設定画面（メンバー削除・他の権限、外部連携、インポートなど）の移植。単発に切り出した繰り返し予定の編集も実機で確認する。
4. **通信と位置共有の復旧**：オフライン編集の保存キューと更新競合処理を設計・実装する。端末再起動・アプリ更新後の位置共有再開は実装済み。Androidの権限別と共有OFF・ログアウト後を実機で検証する。
5. **機能比較**：Webの画面・権限・入力・エラー時の復旧を一覧にし、未移植の設定や細かな操作を埋める。Google Calendar／Tasksの接続状態・最終同期は必要時だけ読むAndroid用APIと画面を追加済み。同期エラーの詳細、接続・解除・再試行などの管理操作はWebとの契約・権限を照合してから移植する。Web変更時はAndroidへの影響も確認する。

位置共有の実機確認では、共有ONで再起動して再開、共有OFF・ログアウト後の再起動で再開しない、バックグラウンド権限を外した再起動で再開しない、アプリ更新後の再開を確認します。Android 10以降は位置情報の「常に許可」が前提です。

APK配布の判断は実機E2Eと署名・更新経路の確認後に行います。公開ストアへの登録は想定しません。
