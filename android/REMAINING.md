# Android ネイティブ化の残作業

PR #1143 は開発中です。Google Homeの読み上げ・音楽は依頼どおり後回しにします。iPhoneの位置共有は既存の外部アプリを使います。

## 完了済みの範囲

実装済みの操作と端末キャッシュは [README.md](README.md) に記載しています。Webと同じD1を既存API経由で使用します。カレンダー、チェックリスト、伝言、育児記録、スタンプ、Android位置共有の主な操作をネイティブ画面へ移しました。ログインのみ既存Web画面を使います。家族固有のPWAアイコンはホーム画面ショートカットへ反映できます。

## 残りの優先順位

1. **APIとAPKの整合**：デバッグAPKはAndroid CIの `familytodo-android-debug` artifactとして7日間保存される。ただし現状のアプリは本番URLを固定で使い、PR #1143 のAndroid用APIは本番未反映。APIが反映されるまで全機能の実機テストを開始できない。反映前にプレビュー環境で認証・D1・位置情報が安全に検証できるなら、専用ビルドの接続先を用意する。
2. **実機確認と配布**：Galaxy A21などの実機でログイン、権限、画面の表示、写真、スタンプ、位置共有、オフラインからの復帰を一通り確認する。署名鍵を安全に保管し、同じ鍵で更新可能なAPKを作る。CI成功は端末での動作保証ではない。
3. **日常操作の差分**：育児記録のWebと同等の詳細グラフ（ミルク・睡眠の簡易グラフは実装済み）、残るWeb設定画面（メンバー削除・権限、外部連携、インポートなど）の移植。単発に切り出した繰り返し予定の編集も実機で確認する。
4. **通信と位置共有の復旧**：オフライン編集の保存キューと更新競合処理を設計・実装する。端末再起動後の位置共有はOSの起動制限とユーザーの共有ON/OFFを踏まえて実装・検証する。
5. **機能比較**：Webの画面・権限・入力・エラー時の復旧を一覧にし、未移植の設定や細かな操作を埋める。Web変更時はAndroidへの影響も確認する。

APK配布の判断は実機E2Eと署名・更新経路の確認後に行います。公開ストアへの登録は想定しません。
