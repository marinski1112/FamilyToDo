### 今回まとめて追加した操作

- 選択した親タスクから子タスクをネイティブ作成。親IDと家族／個人の公開範囲を引き継ぎ、Web同様に初期値は期限なし・カレンダー非表示。イベントの子・さらに深い子は作成しない。
- 保存失敗・入力エラーで作成画面が閉じず、入力を残して再試行できる。保存中の二重送信を防ぎ、同じ内容の再試行は同じ登録キーを使う。通常のタスク／イベント作成も入力を保持。
- 子タスク行はAPIの編集権限に従い、深い子の追加ボタンを出さない。日付・時刻の表示値を既存API形式から変換。
- タスク・イベントと買い物・持ち物に検索ボタン／インライン検索欄を追加。表示中の一覧を絞り、閉じると復元する。検索で追加のサーバー読取は行わない。
- v0.1.171のホーム、カテゴリ操作、カレンダー装飾、伝言、家族ログのUI変更も含む。

### インストール

v0.1.171とは署名証明書が異なります。旧アプリへの上書き更新はできず、入れ替える場合は旧アプリの削除と再ログインが必要です。端末内設定・未送信下書きは消えるため先に保存してください。Web側に保存済みの家族データは残ります。

固定署名は未設定です。継続的な上書き更新には既存内部配布ワークフローの署名用GitHub Secretsの初回設定が必要です。連携からSecretsを設定できず、鍵をソースやログへ保存していません。途中版の入れ直しは不要です。

地図・履歴、日誌詳細、食材、一部管理は認証済みアプリ内Web画面を使います。LINEログイン、実サーバー同期、写真選択、日本語IME、OS権限、バックグラウンド位置共有は実機確認が残ります。
