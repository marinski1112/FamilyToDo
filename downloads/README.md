### 今回の修正

- カレンダーとチェックリストの左右スワイプで月を切り替える。左は翌月、右は前月。チェックリストは月末の日付を補正する。縦スクロール・短い横移動・入力操作は月を変更しない。
- 買い物・持ち物を両方表示。種別選択は追加・カテゴリ作成・セットの操作先を選ぶ。カテゴリの名前・並び・ドラッグ・API保存先は種別ごとに保つ。
- 伝言を開くと最新の一番下へ移動。過去を読む途中の更新と以前の伝言の追加では、見ている位置を保つ。更新でも読み込んだ過去のページを残し、重複IDを除く。自分のテキスト送信後は最新へ移動する。
- v0.1.175までの子タスク・検索・カテゴリ操作・カレンダー装飾・ホーム等の修正を含む。

### インストール

v0.1.175とは署名証明書が異なります。旧アプリへの上書き更新はできず、入れ替える場合は旧アプリの削除と再ログインが必要です。端末内設定・未送信下書きは消えるため先に保存してください。Web側に保存済みの家族データは残ります。

固定署名は未設定。今後の上書き更新には既存内部配布ワークフローの署名用GitHub Secretsの初回設定が必要です。連携からSecretsを設定できず、鍵をソースやログに保存していません。途中版の入れ直しは不要です。

地図・履歴、日誌詳細、食材、一部管理は認証済みアプリ内Web画面を使います。LINEログイン、実サーバー同期、写真選択、日本語IME、OS権限、バックグラウンド位置共有は実機確認が残ります。
