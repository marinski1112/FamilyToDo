### 今回の反映

- チェックリストの前日・翌日・日付指定。日付選択は既存APIの2000〜2100年範囲。同じ月の日付変更は取得済みデータを使用。
- カレンダーの年月指定・今月への復帰・今日のチェックリストへの移動。「すべて／共通／自分専用」でタスク・予定と定期予定を切り替える。Web同様に買い物・持ち物の件数は変えず、フィルタ変更による追加読取はなし。
- 買い物・持ち物を一つの検索欄で検索。閉じたカテゴリ内の項目名にも一致し、追加先切替やカテゴリ開閉後も入力を保持。空カテゴリは種別アイコン付きで一か所へまとめる。完了済みは両種別の合計件数を表示。
- 明示的に無効化されたカテゴリの残存項目を、その種別の未分類から確認できるようにする。表示だけを救済し、保存済みデータは変更しない。
- 伝言本文下にリアクション件数と自分の選択状態を表示。既存チップのタップで切替、新しい候補は長押しメニューから選択。連打・読み取り専用からの送信を防止し、失敗時は前の件数を保持。読み込みは新規ページの最大40件に限定。
- v0.1.180の月スワイプ・両リスト表示・伝言の最新初期位置／履歴位置維持と、以前のUI変更も含む。
