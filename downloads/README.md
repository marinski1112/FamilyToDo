今回の変更をまとめた版です。途中版ごとのインストールやログイン確認は不要です。

### 今回の変更

- ホーム：Webの要対応カード、4つの実数カウンター（今日の家族ログを含む）、昨日の日誌本文・集計、開閉する占いをネイティブ表示。元の認証済みホームHTMLから表示値だけを読み、サーバーの追加変更は不要。
- カレンダー：日付欄のスタンプを3件まで重ねて表示し、残件数・拡大プレビュー・長押し操作を追加。背景ステッカーは元のAPIを使い、家族公開／自分だけで設定・削除。22%の背景濃度と個人背景の優先をWebに合わせた。
- 背景の保存失敗時は選択を残して再試行できる。読み取り専用では書き込まない。画像取得は重複を抑制。
- 前版のカテゴリ名編集・移動・空カテゴリ分類、予定帯・祝日、伝言の吹き出し、家族ログの行編集も含む。

### インストールする場合

v0.1.168と今回のAPKは署名証明書が異なることを確認済みです。同じアプリへの上書き更新はできません。新規インストールには旧アプリの削除と再ログインが必要です。端末内設定・未送信下書きは削除されるため、先に保存してください。Web側の保存済みデータは残ります。今回は途中版の実機確認を求めていません。

再ログインを避ける継続的な上書き更新には、同じ配布署名鍵を使う既存の内部配布ワークフローとGitHub Secretsの初回設定が必要です。連携からSecretsを設定できないため未完了です。鍵をリポジトリやログへ保存していません。

位置の地図・履歴、日誌の詳細、食材、一部管理はアプリ内Web画面を利用します。LINEログイン、実サーバー同期、日本語IME、写真選択、OS権限、バックグラウンド位置共有は実機確認が残ります。
