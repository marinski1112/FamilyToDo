# Android テスト版

## 最新版 v0.1.159

**[APKを直接ダウンロード](https://raw.githubusercontent.com/marinski1112/FamilyToDo/android-test-downloads/downloads/FamilyToDo-test-v0.1.159.apk)**

AndroidのChromeで開いて保存できます。ファイル名：`FamilyToDo-test-v0.1.159.apk`。

### インストール

旧v0.1.149とは署名が異なるため、今回は旧アプリを削除して新規インストールが必要です。Webと共有する保存済みデータは残ります。端末内の設定・未送信の下書きは削除されるため、先に送信・保存してください。インストール後はLINEログインと位置共有の設定を確認してください。固定配布署名は未整備です。

### 今回の変更

ホーム、チェックリスト、カレンダー、家族ログ、伝言とページ導線を調整。チェックリストは名前のタップ編集とチェック操作を分離、連続追加・保存失敗時の復元を確認。カレンダーの曜日ずれと下部ナビの文字切れも修正。

位置の地図・移動履歴、日記、食材、詳細管理はアプリ内でWeb画面を利用します。完全なネイティブ移植・操作一致は未完了です。

### 確認済みの範囲

Android 11・15、360dp幅、ライト／ダークのエミュレーターで架空データを使用。主要タブの表示、名前編集とチェックの分離、保存／失敗復元、買い物・持ち物の分離、連続追加、日付と曜日の一致、伝言入力欄を確認。

LINEログイン、実サーバー同期、端末固有の日本語IME、写真選択、OS権限、バックグラウンド位置共有は実機確認が必要です。
