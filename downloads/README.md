実機画像でv0.1.191とWeb版の配置・余白に大きな差があったため、見た目を修正しました。

- チェックリスト: 買い物・持ち物のカテゴリを区切り線の一括一覧へ。タスク/イベント、買い物/持ち物、完了状態、追加・カテゴリ・セット操作を小型化。四角チェックと丸い詳細ボタン。直接編集・独立開閉・ドラッグ・長押しの既存操作は維持。空の入力状態メッセージを隠し余白を削減。
- カレンダー: 表示設定、年月、今月、前後月を一列へ。追加・管理を右下へ。表示範囲と今日のチェックリスト入口は表示設定内。日付タップ、月スワイプ、年月指定、イベント帯/並び順/件数/スタンプは維持。
- 家族ログ: 対象・日付・管理を統合したヘッダー。時刻/対象・アイコン・内容の横並び一覧。対象に記録がない場合の空表示、横スクロールのクイック記録、下部の日記・食材・まとめリンク。記録追加/タイマーは歯車から。
- 伝言: 家族名・補足・更新を小型ヘッダーに集約。最新位置、履歴保持、LINEアイコン、写真/スタンプ、長押しリアクションの操作を維持。
- 共通: 過大なボタン余白を削減、テスト版見出しを取り除き、ホームの「⚙️ 管理」→「表示モード（ライト・ダーク）」で端末準拠/ライト/ダークを選択可能。
