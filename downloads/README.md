### インストール

旧v0.1.159とは署名が異なるため、旧アプリを削除して新規インストールしてください。Webと共有する保存済みデータは残ります。端末内の設定・未送信の下書きは削除されるため、先に送信・保存してください。再ログインと位置共有設定の確認が必要です。固定配布署名は未整備です。

### 今回の変更

- ホーム：Web風の2列件数カード、3列ショートカット、コンパクトな余白。
- チェックリスト：元ソースと同じJST境界による空カテゴリ分類とクラスター、名前編集・追加導線、カテゴリ取得後の再表示。
- カレンダー：単日の予定4件、日跨ぎ帯と重なりの別段表示、残件数、祝日、前後月の日付、タスク・買い物・持ち物件数。
- 伝言：Webの配色、日付表示、128dpスタンプ、本文幅の吹き出し、自分の伝言と時刻の右寄せ、緑の送信ボタン。
- 家族ログ：記録行のタップ編集と長押し操作、コンパクトな記録カード・クイックボタン。
