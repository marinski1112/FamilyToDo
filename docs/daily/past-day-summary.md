# 日付によるチェックリストと総括の切り替え

2026-10-06のユーザー合意に基づくWeb実装。家族の設定タイムゾーンで「今日」を決め、48時間ではなく暦日で判定する。

| 日付 | 表示 |
| --- | --- |
| 当日・未来 | 既存チェックリスト |
| 昨日 | 訂正の猶予として既存チェックリスト |
| 一昨日以前 | 既存家族日記内の日別総括 (`view=day`) |

カレンダーの短押し、チェックリストの前日・翌日、総括の日付選択は同じ境界を使う。日別総括から昨日以降へ進むとチェックリストへ戻る。未認証時、POST、期限切れ一覧の追加取得は既存経路を維持する。

## 表示するもの

- 現在保存された予定。参加・実施済みとは推測しない。
- この日の現在の献立と、調理済み記録の有無。別revisionの調理記録は現在の料理名と結び付けない。食べた実績とは扱わない。
- 家族ログの時刻・対象・種別・短い本文。削除済み、別家族、設定で非表示の大人ログは表示しない。先頭50件を超える場合は詳細への導線と省略表示を出す。
- 保存済み日誌の家族共有タスク完了、家事、取得できた移動・滞在。位置未取得区間は滞在と推測しない。
- この日に予定された現在未完了のタスク。自動完了・移動・削除は行わず、今日のチェックリストの期限切れ欄も維持する。
- 取り込んだ育児日記の原文・写真。月別日記・検索への導線を維持する。

表示処理は読取りのみ。日誌生成・修復・AI呼出し・Cron変更・データ移行は行わない。保存済みHOT日誌が取得できない日は「記録なし」と断定せず、未生成・保存対象外・アーカイブ済みの可能性を表示する。予定／献立／家族ログの取得失敗はセクション単位で示し、ほかの表示を残す。

## 検証と残る範囲

`family-day-overview.test.mjs` は合成SQLiteで日付境界、月年・閏日、家族タイムゾーン、権限・家族分離、未完了保持、調理revision、ログ設定、失敗復帰、GETの書込み・AI呼出しなしを確認する。既存の日誌・チェックリスト・カレンダー契約も維持する。

Androidネイティブの日付切替は未移植。Webへ開く導線ではWebの同じ境界が適用される。Androidの実認証検証、大きい文字・IME・実端末表示は、このWeb検証の代わりにはならない。
