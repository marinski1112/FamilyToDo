# レシピ一覧と復帰

家族のレシピ一覧は料理名で検索し、名前・ID順に30件ずつ表示する。`GET /api/meals/v1?view=recipe_catalog` は家族と非表示状態で絞り、次ページのカーソルを返す。概要APIの200件制限とは独立している。`0019_recipe_catalog_order.sql` の索引を使い、一覧取得時に材料・手順の全文は返さない。検索は名前の部分一致で、家族内の検索対象数に応じて読み取り量が増える。

一覧から外したレシピは「非表示のレシピ」から戻せる。復帰は家族ID・レシピID・revisionを照合し、同じrevisionでの再試行を許す。レシピの再作成や、保存済み献立のスナップショット変更は行わない。削除・保存期間の自動変更は追加していない。

詳細の「献立に入れる」は日付を選択して週間献立に移動する。主菜は主菜欄、副菜などは複数の副菜欄に反映し、他の日の選択を保持する。主菜の入れ替えは確認する。この移動だけでは保存せず、献立表で本人が確認・保存する。副菜だけを選んだ日には主菜の選択が必要。

公開検索のサイト選択はブラウザ内に記憶する。ホットクック機種の既存記憶とは別で、家族共通設定ではない。検索先への送信は検索ボタンを押した場合だけ。
