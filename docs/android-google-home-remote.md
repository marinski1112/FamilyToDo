# 外出先からGoogle Homeで伝言を読み上げる（開発中）

AndroidのGoogle Home SDK 1.11.0（Mavenライブラリ17.1.0）を使用する。
SDKライブラリのKotlinメタデータ2.4に対応するため、Kotlin 2.4.20を使用する。
SDK ZIPはリポジトリに含めない。ダウンロード済みZIPを展開し、そのMavenルートを渡す。

```sh
gradle -p android :app:assembleDebug \
  -PfamilytodoHomeSdkRepository=/absolute/path/to/extracted/home.android.sdk \
  -PfamilytodoVersionCode=206
```

Mavenルート直下に `com/google/android/gms/play-services-home/17.1.0/` が必要。
SDKの有無を切り替えるときは `gradle -p android clean` を先に実行し、DEXの最低OSキャッシュを消す。
SDKを指定しない通常ビルドは従来のCastを利用し、遠隔読み上げは利用不可と表示する。
SDK対応ビルドはAndroid 10以上。通常ビルドの最低バージョンはAndroid 8を維持する。

## Google側の設定と実機確認

実際に使用するAPKの署名証明書SHA-1とパッケージ名 `jp.marinski.familytodo` をAndroid OAuthクライアントに登録する。
Google Home SDKのプロジェクト設定とOAuth同意画面・テストユーザーも確認する。
署名が変わったAPKではOAuthの登録を更新する必要があるため、継続配布前に固定署名を用意する。
秘密鍵・パスワードはコードやチャットに貼り付けない。

1. 伝言の＋メニューから「外出先からの読み上げ設定」を開く。
2. Googleの画面で家へのアクセスを許可し、対応する家全体またはスピーカーを選ぶ。
3. 伝言・スタンプの送信画面で「送信後すぐGoogle Homeで読み上げる」をチェックする。
4. Wi-Fiを切り、モバイル通信から送信する。伝言が一件保存され、自宅で音が出ることを確認する。
5. 通知予約を付けても、読み上げは送信直後になることを確認する。予約日時の読み上げは未実装。
6. 許可取消・オフライン・スピーカー削除・ログアウト・家族切替・画面終了を確認する。

受付成功は音声再生の実測成功を意味しない。実際のスピーカーでの試験を完了するまで、本番対応済みとは扱わない。
Web版からの遠隔実行・サーバー常駐実行はこの変更の対象外。

## 重複と後片付け

伝言保存成功後、返された伝言IDでのみSDKを呼ぶ。本文を伝言APIへ再送しない。
同じ家族・ログインセッション・伝言IDの実行状態と送信先・本文のハッシュを端末へ保存する。
実行要求前にEXECUTINGを永続化する。実行後のタイムアウトやクラッシュはUNKNOWNとなり、再実行しない。
実行前の失敗だけ「読み上げだけ再試行」を表示する。受付済み要求は再実行しない。

手動開始・最大実行回数1の一時オートメーションを作成し、停止後に削除する。
削除できなかったものは自アプリが記録したIDだけを後の設定時に再確認する。
既存の他のオートメーションは変更しない。ログアウト・家族変更では実行中処理を中止する。
GoogleトークンはSDKに任せ、アプリで保存しない。本文はSDKへの要求と一時オートメーションに含まれる。

重複防止状態のテストはAndroid CIに含まれる。SDK実装はZIPを指定したビルドでも別途検証する。
